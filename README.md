# Prompt Master Criades V7.2

Aquesta versió parteix directament de V7.1.2 i conserva el motor bilingüe i la resta de controls.

## Canvis d'uniforme
- MASTER B: la banda horitzontal del pitet és obligatòria i utilitza exactament el mateix teixit, color, patró, escala i orientació que el vestit.
- MASTER B: la banda del pitet queda coordinada amb les bandes de les dues butxaques com un sistema de tres bandes.
- Opció `C amb pitet · Servei formal + pitet/babero amb encaix`.
- MASTER C amb pitet conserva el vestit formal de C però substitueix el mig davantal per un davantal blanc formal amb pitet i encaix blanc obligatori.
- Separació explícita entre el davantal de treball B i el davantal formal C amb pitet.
- Nou selector `Acabat del vestit` amb `Sense encaix` i `Encaix discret al coll i màniga`.
- L'acabat amb encaix aplica encaix blanc fi, pla i discret al perímetre visible del coll i a la vora de totes dues mànigues.
- Aquest encaix pertany al vestit, no al davantal, i només és compatible amb A, B i B coordinat. C, C amb pitet i D conserven els seus sistemes propis.
- El Scene-Aware Narrative Engine queda fora d'aquesta versió; es conserva el motor narratiu de V7.1.2.
